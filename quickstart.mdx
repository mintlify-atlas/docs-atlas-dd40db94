---

This guide walks you through installing Koodo Reader, importing a book, and opening it for the first time. The whole process takes less than five minutes.

<Steps>
  <Step title="Install Koodo Reader">
    Download and install Koodo Reader for your platform. Desktop (Windows, macOS, Linux), mobile (Android, iOS), and web options are all available.

    See the [Installation](/installation) page for platform-specific instructions, including Homebrew, Scoop, and Docker options.
  </Step>
  <Step title="Import your first book">
    Koodo Reader supports several ways to add books to your library:

    **Drag and drop**

    Drag one or more book files directly onto the Koodo Reader window. The files are imported immediately and appear in your library.

    **File menu**

    Click **File** in the menu bar, then select **Import** and choose your file(s) from the file picker.

    **Import button**

    Click the import button (the cloud icon with an upward arrow) in the top-right corner of the library view to open the file picker.

    **Cloud storage import**

    Connect a cloud storage provider (OneDrive, Google Drive, MEGA, Yandex Disk, Box, FTP, SFTP, WebDAV, SMB, or S3-compatible object storage) and import books directly from your cloud account without downloading them first.

    <Tip>
      To import an entire folder of books at once, drag the folder onto the Koodo Reader window or use **File > Import folder**. Koodo Reader scans the folder recursively and imports all supported files in one step.
    </Tip>
  </Step>
  <Step title="Open a book and start reading">
    Click any book cover or title in your library to open it in the reader.

    From the reader you can:

    - Adjust **font size**, **font family**, **line spacing**, and **margins** from the settings panel (click the **Aa** button in the toolbar)
    - Switch between **single-column**, **two-column**, and **continuous scrolling** layouts
    - Enable **night mode** or choose a custom **theme color**
    - Add **bookmarks**, **highlights**, and **notes** by selecting text
    - Use the **AI tools** (dictionary, translation, summarization) by selecting a word or passage
    - Enable **text-to-speech** to have the book read aloud
  </Step>
  <Step title="Set up cloud sync (optional)">
    To keep your library and reading progress in sync across devices, connect a cloud storage provider.

    1. Open **Settings** (the gear icon in the sidebar).
    2. Go to **Sync and backup**.
    3. Select your cloud provider and sign in.
    4. Choose a sync folder and click **Save**.

    Koodo Reader supports OneDrive, Google Drive, Dropbox, MEGA, pCloud, Yandex Disk, Box, FTP, SFTP, WebDAV, SMB, and S3-compatible object storage.

    See the [Sync overview](/sync/overview) for a full setup guide for each provider.
  </Step>
</Steps>
