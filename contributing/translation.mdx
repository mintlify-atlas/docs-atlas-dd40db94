Koodo Reader is available in over 40 languages, all maintained by community contributors. Translation files are plain JSON, so no coding experience is required.

## Translation file format

Each language has a single file at:

```
src/assets/locales/{lang}/translation.json
```

The file contains key-value pairs where the key is the English term used in code and the value is the translated string.

```json
{
  "Books": "Books",
  "Recent": "Recents",
  "Bookmarks": "Bookmarks",
  "Notes": "Notes",
  "Highlights": "Highlights",
  "Shelf": "Shelf",
  "Dictionary": "Dictionary",
  "New version available": "New version available"
}
```

Untranslated terms appear at the bottom of each file with the English value still in place — those are the ones that need your attention.

## Edit an existing translation

<Steps>
  <Step title="Find your language">
    Locate your language in the supported languages table below and note its language code.
  </Step>
  <Step title="Open the source file">
    Navigate to `src/assets/locales/{lang}/translation.json` in the repository. You can view it directly on GitHub using the links in the table below.
  </Step>
  <Step title="Identify untranslated terms">
    Untranslated strings are listed at the bottom of the file. They still contain the English value as a placeholder.
  </Step>
  <Step title="Translate the terms">
    Replace each English placeholder value with the correct translation in your language.
  </Step>
  <Step title="Submit your changes">
    Submit your updated file via a [GitHub issue](https://github.com/koodo-reader/koodo-reader/issues/new?assignees=&labels=submit+translation&projects=&template=submit_translation.yml) or open a pull request. Both are welcome.
  </Step>
</Steps>

## Add a new language

<Steps>
  <Step title="Download the English source file">
    Download [`src/assets/locales/en/translation.json`](https://github.com/koodo-reader/koodo-reader/blob/master/src/assets/locales/en/translation.json) from the repository. This is the authoritative source for all translatable strings.
  </Step>
  <Step title="Translate all strings">
    Replace every English value with the translation in your target language. Keep all keys unchanged.
  </Step>
  <Step title="Submit your translation">
    Submit the completed file via a [GitHub issue](https://github.com/koodo-reader/koodo-reader/issues/new?assignees=&labels=submit+translation&projects=&template=submit_translation.yml) or open a pull request. Include the language name and its BCP 47 code in your submission.
  </Step>
</Steps>

<Tip>
  You don't have to translate every string at once. Submitting partial translations via a GitHub issue is perfectly fine — other contributors can build on your work.
</Tip>
