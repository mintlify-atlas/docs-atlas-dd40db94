Koodo Reader is a modern ebook manager and reader built for readers who want control over their library. It runs natively on Windows, macOS, Linux, Android, and iOS, and is also available as a hosted web app — all from a single open-source codebase.

## Supported formats

Koodo Reader opens all major ebook and document formats without additional plugins:

| Category | Extensions |
|---|---|
| EPUB | `.epub` |
| PDF | `.pdf` |
| Mobipocket / Kindle | `.mobi`, `.azw3`, `.azw` |
| FictionBook | `.fb2` |
| Comic book archives | `.cbr`, `.cbz`, `.cbt`, `.cb7` |
| Rich text | `.docx`, `.md` |
| Plain text | `.txt` |
| HyperText | `.html`, `.htm`, `.xhtml`, `.mhtml`, `.xml` |

<Note>
  DRM-protected files (e.g., books purchased from Amazon) are not supported. Only DRM-free files can be opened.
</Note>

## Supported platforms

| Platform | Delivery method |
|---|---|
| **Windows** | Installer (.exe), portable, or Scoop |
| **macOS** | DMG (Intel & Apple Silicon) or Homebrew |
| **Linux** | AppImage, .deb, .rpm, Snap, or Scoop |
| **Android** | APK download from koodoreader.com |
| **iOS** | Download from koodoreader.com |
| **Web** | Hosted at [web.koodoreader.com](https://web.koodoreader.com) — no install required |

## Key features

**Cloud sync and backup**
Sync your library and reading progress across devices using OneDrive, Google Drive, Dropbox, MEGA, pCloud, Yandex Disk, Box, FTP, SFTP, WebDAV, SMB, or S3-compatible object storage.

**Book import from cloud storage**
Import books directly from OneDrive, Google Drive, MEGA, Yandex Disk, Box, FTP, SFTP, WebDAV, SMB, or object storage — no manual download required.

**AI-powered tools**
Use built-in AI for dictionary lookup, passage summarization, and translation while reading. Extend AI providers through plugins.

**Text-to-speech**
Listen to any book with the built-in TTS engine. Add custom TTS voices via plugins.

**Annotations**
Add highlights, bookmarks, and notes to your books. Export annotations for use outside the app.

**Reading customization**
Adjust font size, font family, line spacing, paragraph spacing, margins, background color, text color, and brightness. Switch between single-column, two-column, and continuous scrolling layouts. Enable night mode or set a custom theme color.

**Text styling**
Apply highlighting, underline, bold, italic, and shadow to selected text.

**Plugin support**
Extend Koodo Reader with community plugins for custom TTS voices, AI providers, and more.
