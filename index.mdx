## Supported formats

Koodo Reader handles all major ebook and document formats out of the box:

| Format | Extensions |
|--------|------------|
| EPUB | `.epub` |
| PDF | `.pdf` |
| Mobipocket / Kindle | `.mobi`, `.azw3`, `.azw` |
| FictionBook | `.fb2` |
| Comic book archives | `.cbr`, `.cbz`, `.cbt`, `.cb7` |
| Rich text | `.docx`, `.md` |
| Plain text | `.txt` |
| HyperText | `.html`, `.htm`, `.xhtml`, `.mhtml`, `.xml` |

## Platforms

Koodo Reader runs natively on every major platform:

<Steps>
  <Step title="Desktop">
    Native apps for **Windows**, **macOS**, and **Linux** via Electron. Install from the website, Scoop, Homebrew, or your Linux package manager.
  </Step>
  <Step title="Mobile">
    Native apps for **Android** and **iOS** available from the respective app stores.
  </Step>
  <Step title="Web">
    Use the hosted web version at [web.koodoreader.com](https://web.koodoreader.com) — no installation required.
  </Step>
  <Step title="Self-hosted">
    Run your own instance with Docker for full data control and offline access.
  </Step>
</Steps>
